## 🔥 Featured Project

### 🏦 Banking Transaction Anomaly Detector

A rule-based system designed to identify suspicious banking transactions using **OOP and Data Structures & Algorithms**.

The project focuses on making anomaly detection **efficient, explainable and easy to extend**.

**Key features:**

* 🔹 Account & Transaction modelling using OOP
* 🔹 Multiple anomaly-detection rules
* 🔹 Amount spike detection
* 🔹 Repeated transaction detection
* 🔹 Unusual-time activity detection
* 🔹 Transaction velocity analysis
* 🔹 New-payee detection
* 🔹 Structuring detection
* 🔹 Priority queue for ranking suspicious alerts
* 🔹 Graph-based detection of cross-account patterns
* 🔹 Configurable rules using JSON

**Data Structures used:**
`Hash Map` • `Deque` • `Priority Queue` • `Graph`

**Goal:** Build a practical project that demonstrates how **OOP design and DSA can work together in a real-world FinTech problem.**
