⚖️ NAWI Test Report Generator — Smart India Hackathon 2026 (SIH26035)
A full-stack web application built for Smart India Hackathon 2026, under the problem statement issued by the Ministry of Consumer Affairs, Food & Public Distribution, to automate the generation of test reports for Non-Automatic Weighing Instruments (NAWIs) as per OIML Recommendation R-76.
The system replaces manual, spreadsheet-based test reporting with a structured, validated and auditable digital workflow for legal metrology laboratories.
Key features:
🔹 Digital data entry for instrument details, specifications & lab conditions
🔹 Structured forms for all OIML R-76 test procedures
🔹 Automated calculation of permissible errors & compliance status
🔹 Rule-based pass/fail determination as per OIML R-76 (MPE & tolerance logic)
🔹 Role-based dashboard (Lab Technician, Quality Reviewer, Lab Manager, System Admin)
🔹 Standardized report generation in PDF & editable DOCX formats
🔹 Digital signatures on finalized reports
🔹 Searchable report repository with instrument-wise test history
🔹 Secure authentication with JWT + Role-Based Access Control
Tech stack:
Frontend: Next.js, Tailwind CSS, Shadcn UI, Zustand, Lucide Icons, Leaflet.js
Backend: FastAPI, Uvicorn, Pydantic, Celery + Redis (async tasks)
Calculation Engine: Python module encoding OIML R-76 rules (MPE & tolerance logic)
Database: PostgreSQL (metadata, test logs, audit trails)
Document Engine: python-docx, WeasyPrint / Puppeteer (PDF export)
Storage & Cache: MinIO / AWS S3, Redis
Security: JWT, RBAC, PyOpenSSL (digital signatures)
DevOps: Docker, Nginx, GitHub Actions CI/CD
Goal: Demonstrate how a compliance-heavy, real-world government workflow can be turned into an accurate, consistent and efficient software system — combining full-stack development with domain-specific rule-based logic.
